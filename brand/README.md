# Trackwell logo: Period Grid

A T built from five class-period blocks (three across the school day, two down); the top-right block is stamped violet. Every file is plain, editable SVG (rectangles and live text, no rasters), so it opens in Figma, Illustrator or Inkscape. The wordmark is live text in **Public Sans** semibold (Google Fonts), letter-spacing −1.5%.

| File | Use |
|---|---|
| `icon-dark.svg` / `icon-light.svg` | Bare mark for dark / light backgrounds |
| `icon-mono-black.svg` / `icon-mono-white.svg` | One-colour mark |
| `logo-horizontal-*.svg` | Mark + wordmark lockups (dark, light, mono black, mono white) |
| `app-icon-light.svg` / `app-icon-dark.svg` | Tile icons (dark tile / light tile) |
| `favicon.svg` | Adaptive favicon (follows the browser theme) |

Raster icons for platforms that need them are in `public/` (`favicon-32.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`). Colours: ink `#ecebe7` / `#1a1917`, stamp violet `#a276e4` / `#7444c0`, ground `#0e0d0c`.
